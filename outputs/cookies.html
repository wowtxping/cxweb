These policies are provided in English and Simplified Chinese. Please email us if you need help understanding them.

1. Our approach

Cookies are small browser records; localStorage is a different browser storage mechanism to which similar privacy rules can apply. This website keeps essential privacy choices and offers two optional features: remembered language and Tencent / Knocket chat. Both optional features are off until allowed. We do not install an advertising pixel or a separate site analytics service. Hosting/security processing is described in the Privacy policy.

2. Essential privacy choices

spring-snow-privacy-v1 is first-party localStorage containing the policy version, two permission flags, choice source and saved/expiry timestamps. It is necessary to respect your selection, is not a visitor identifier, and expires after 180 days. It is saved when you make a choice; if browser storage is blocked, a choice can apply only to the current page.

3. Optional language preference

chunxue-language is first-party localStorage holding a language code. It is read and written only if you allow remembered language. Its effective lifetime is limited by the 180-day privacy choice, and it is removed when permission expires or is withdrawn. Without permission, you can still change the current language; internal page links may use a public lang URL parameter to carry that choice without browser storage.

4. Optional chat storage and requests

Tencent / Knocket is loaded only after chat permission and activation. The SDK may store visitor/session data, authentication or message cache and service state, including keys starting with knocket:, TIM_, visitorId or imUserInfo. Names and retention can vary with the provider version and account settings. The provider may process IP/device data and service diagnostics. Our script-source restrictions block the separately identified trtc.io/js/shence814.min.js analytics loader; this is not a claim that all provider operational logging is disabled. See Tencent / Knocket privacy information.

5. Rejecting or withdrawing permission

Use to reject optional features or change either permission. Allowing chat does not automatically download it on every page; it still waits for activation. If you turn off chat after the SDK has loaded, the page reloads to stop it and removes identifiable chat storage/cookies accessible to this site. We cannot delete HttpOnly or third-party-domain cookies or provider-held messages from this page. Your browser can clear site data, and info@sscakh.com can receive requests about delivered enquiries.

6. Hosting, external sites and changes

Cloudflare provides hosting/security and may use provider-managed security cookies when its protections require them; availability and lifetime depend on the protection actually used. See the Cloudflare privacy policy. We do not embed Google Maps: a selected address link opens its external page. External sites control their own storage. We update this policy when the site’s storage practices change and request a new choice when the consent version changes.
